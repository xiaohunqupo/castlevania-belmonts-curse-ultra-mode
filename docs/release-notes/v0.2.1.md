补丁版 / Patch release.

## 简体中文

- **BepInEx Config Manager 冲突防护**：同时安装时不再在启动阶段崩溃。检测到 Config Manager 后会自动关闭「启用奥创模式」、跳过全部 Harmony 补丁，并在该选项说明里提示冲突；卸掉 Config Manager 并重启后即可再开。感谢 **Vaatu8** 的报告。
- **被动魔导器装备框**：自动生效的魔导器在魔导器列表里会显示与槽位装备相同的已装备框；点击仍可装进槽位。

**下载哪个**：

- `UltraMode-v0.2.1-with-BepInEx.zip`：**整合包**，内含官方原版 BepInEx 6 IL2CPP x64 be.788。没装过 BepInEx 的选这个，解压到游戏根目录即可；第一次启动需要几分钟，请保持联网。
- `UltraMode-v0.2.1.zip`：只有本 mod。已经装了旧版本的玩家下载这个，覆盖 `BepInEx/plugins/UltraMode/` 即可，配置会保留。

## English

- **BepInEx Config Manager conflict guard**: installing both no longer fatals on startup. When Config Manager is detected, Ultra Mode turns itself off, skips all Harmony patches, and the Enable option hint explains the conflict; remove Config Manager and restart to enable Ultra Mode again. Thanks to **Vaatu8** for the report.
- **Passive charm equipped frame**: auto-active charms show the same equipped frame in the charms list as slotted ones; clicking still equips them into a slot.

**Which download**:

- `UltraMode-v0.2.1-with-BepInEx.zip`: **all-in-one**, includes the official BepInEx 6 IL2CPP x64 be.788. Pick this if you have never installed BepInEx; unzip into the game folder. The first launch takes a few minutes and needs an internet connection.
- `UltraMode-v0.2.1.zip`: this mod only. If you have an older version, download this and overwrite `BepInEx/plugins/UltraMode/`; your settings are kept.
