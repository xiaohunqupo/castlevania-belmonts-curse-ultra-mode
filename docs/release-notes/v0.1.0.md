首个公开版本 / First public release.

## 简体中文

《恶魔城：贝尔蒙特的诅咒》BepInEx 6 IL2CPP 插件，保留原版操作，让手感更跟手：

- **高速反应**：移动、起步急停、转身更快；攻击前摇、后摇分别加速，命中帧与动画同步；钩锁出手和收回更快。
- **镜头**：快速移动和被弹射时镜头跟得上；右摇杆观察范围和速度可调。
- **闪避无敌**：滑铲、后撤步的位移阶段无敌，并有闪光提示；陷阱、即死区域、坠落伤害照常生效。
- **受身**：被击飞时按跳立即恢复控制。
- **攻击弹反**：解锁弹反后，普通攻击在同样的窗口内也能弹反，且不打断攻击。
- **钩锁辅助**：没有目标时不出钩；只有一个可钩目标时自动瞄准；只高亮真正钩得到的锚点。
- **镜子**：镜子前按下即进入，提示里显示"下 交互"；隐士任务后损坏的传送镜子恢复可用。
- **被动魔导器**：获得即生效、不占槽位；五个带负面效果的魔导器默认不自动装备，可单独开启。洞幽石效果常开。
- **设置页**：暂停菜单 → MODS → 奥创模式。装了 Belmont Minimap 或 Belmont UI 时使用它们的页签，都没装时使用内嵌的 Belmont UI，无需安装其他 mod。

**安装**：需要 [BepInEx 6 IL2CPP x64 (be.788)](https://builds.bepinex.dev/projects/bepinex_be)。下载 `UltraMode-v0.1.0.zip`，解压到游戏根目录。详见 [README](https://github.com/xiaohunqupo/castlevania-belmonts-curse-ultra-mode/blob/main/README.zh-CN.md)。

**已知冲突**：与 Charms Unlimited 冲突，请关闭本 mod 的两个自动装备魔导器开关，或者不装 Charms Unlimited。

## English

A BepInEx 6 IL2CPP plugin for **Castlevania: Belmont's Curse** that keeps the original controls and makes them more responsive:

- **Fast response**: faster movement, starts, stops and turns; attack wind-up and recovery sped up separately with hit frames kept in sync; faster whip throw and retract.
- **Camera**: keeps up with fast moves and launches; adjustable right-stick look range and speed.
- **Invulnerable evasion**: no damage during the movement phase of the slide and backdash, shown by a flash. Traps, death zones and fall damage still apply.
- **Knockback recovery**: press Jump while knocked back to regain control at once.
- **Attack parry**: once parry is unlocked, normal attacks parry in the same window without being interrupted.
- **Whip assist**: no empty whip; a lone reachable anchor is hooked whatever you face; only reachable anchors are highlighted.
- **Mirrors**: press Down to enter at once, with a "Down Interact" prompt; teleport mirrors broken after The Hermit work again.
- **Passive relics**: active once found, no slot needed. The five relics with drawbacks are not auto-equipped by default and have their own switch. The Gloomstone is always on.
- **Settings page**: pause menu → MODS → Ultra Mode. It uses Belmont Minimap's or Belmont UI's tab when one is installed, and an embedded Belmont UI otherwise, so no other mod is required.

**Install**: requires [BepInEx 6 IL2CPP x64 (be.788)](https://builds.bepinex.dev/projects/bepinex_be). Download `UltraMode-v0.1.0.zip` and extract it into the game folder. See the [README](https://github.com/xiaohunqupo/castlevania-belmonts-curse-ultra-mode/blob/main/README.md).

**Known conflict**: Charms Unlimited. Turn off both relic auto-equip switches, or don't install Charms Unlimited.
