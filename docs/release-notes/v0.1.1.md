问题修复版 / Bug-fix release.

## 简体中文

- **修复镜之厅最上层的崩溃**：走到镜之厅最上层那面镜子前游戏会直接崩溃（关掉奥创模式则不会）。原因是"修复破碎镜子"给游戏判断镜子能否使用的方法打了补丁，这个方法太短，补丁破坏了它的内部跳转。现在不再给它打补丁，存档室的破镜子改为只靠换回原来的完好镜子来修复。
- **"修复破碎镜子"配对更准确**：只把破镜子换成它旁边同名的原镜子，存档室和镜之厅中枢的破镜子都能修复，不会再换错；关闭这个开关或关闭奥创模式时，已经替换的镜子当场还原。
- **钩锁辅助**：
  - 附近没有可钩的东西时偶尔仍会挥出钩锁，已修复。
  - 只有一个勾点高亮时偶尔需要按方向才能钩中，已修复：现在会一直锁定瞄准它，直到这次钩锁结束。
  - 钩锁被打断后辅助偶尔整体失效，已修复。
  - 站在钩锁范围边缘时，勾点不高亮却仍能挥出钩锁、然后挥空，已修复：边缘处够不着的勾点按"没有可钩的东西"处理。
- **镜头跟随速度默认值从 2.00x 改为 1.25x**，原来太快容易头晕。已经有配置文件的玩家不会自动改变，可以在设置页手动调整。
- **镜子提示**：能传送的镜子前，提示改为"保存"（存档点）或"信息"，加上"下 传送"（原来是"下 交互"）。某面镜子的检查出错时只跳过这一面，不再影响其他镜子。
- **设置页**：
  - Belmont Minimap 的 MODS 页里按下有时滚动不到下面的行，已修复。
  - "自动装备正面魔导器"一行因为说明文字缺字被跳过，已修复。
  - 去掉了"调试日志"和"快捷键导出调试数据"两行，需要时在配置文件里改 `DebugLogging` / `DumpKeyEnabled`。

**下载哪个**：

- `UltraMode-v0.1.1-with-BepInEx.zip`：**整合包**，内含官方原版 BepInEx 6 IL2CPP x64 be.788。没装过 BepInEx 的选这个，解压到游戏根目录即可；第一次启动需要几分钟，请保持联网。
- `UltraMode-v0.1.1.zip`：只有本 mod。已经装了 v0.1.0 的玩家下载这个，覆盖 `BepInEx/plugins/UltraMode/` 即可，配置会保留。

## English

- **Fixed a crash at the top of the Hall of Mirrors**: walking up to the topmost mirror crashed the game (it did not with Ultra Mode off). "Repair broken mirrors" patched the game's mirror-usable check, a function too short for the patch, which broke a jump inside it. That method is no longer patched; broken save room mirrors are repaired only by bringing back the original intact mirror.
- **"Repair broken mirrors" pairs mirrors exactly**: a broken mirror is only swapped for the original of the same name next to it, so broken mirrors in save rooms and in the Hall of Mirrors hub are both repaired without mixing them up. Swapped mirrors are restored at once when the option or Ultra Mode is turned off.
- **Whip assist**:
  - Fixed the whip sometimes still being thrown with nothing to hook.
  - Fixed a lone highlighted anchor sometimes needing a direction to be hooked: the aim now stays locked on it until the whip ends.
  - Fixed the assist sometimes stopping altogether after an interrupted whip.
  - Fixed the whip being thrown and missing at the edge of reach while the anchor was not highlighted: an anchor just out of reach now counts as nothing to hook.
- **Camera follow speed now defaults to 1.25x instead of 2.00x**, which was fast enough to cause dizziness. An existing config file keeps its value; adjust it on the settings page.
- **Mirror prompt**: at mirrors you can travel from, the prompt now reads "Save" (at a save point) or "Info" plus "Down Teleport" (it used to be "Down Interact"). A mirror whose check fails is skipped on its own instead of affecting the others.
- **Settings page**:
  - Fixed pressing down sometimes not scrolling to lower rows on Belmont Minimap's MODS page.
  - Fixed the "Auto-equip relics without drawbacks" row being skipped because the game font lacked a character of its hint.
  - Removed the "Debug logging" and "Debug dump hotkey" rows; set `DebugLogging` / `DumpKeyEnabled` in the config file when needed.

**Which file**:

- `UltraMode-v0.1.1-with-BepInEx.zip`: **all-in-one**, includes the official BepInEx 6 IL2CPP x64 be.788. Pick this if you have never installed BepInEx; unzip into the game folder. The first launch takes a few minutes and needs an internet connection.
- `UltraMode-v0.1.1.zip`: this mod only. If you already have v0.1.0, download this and overwrite `BepInEx/plugins/UltraMode/`; your settings are kept.
