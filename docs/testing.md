# 测试清单

项目没有自动化测试，所有验证都要在游戏里手动完成。改动后至少回归改动涉及的模块；发布前把整张清单过一遍。

建议打开 `DebugLogging`，边玩边看 `BepInEx/LogOutput.log`。

## 通用

- [ ] 日志里 `n/m features active` 的数量与模块数一致，没有 `disabled for this session`。
- [ ] 按 F10 关闭后，所有功能回到原版；再按一次恢复。
- [ ] 关掉"快捷键开关奥创模式"后按 F10 没有反应；默认设置下按 F11 不会导出，配置文件里打开 `DumpKeyEnabled` 后可以导出；设置页里没有调试相关的行。
- [ ] 在设置页修改滑条和开关后立即生效；"恢复默认"可用。
- [ ] 设置页只出现一次：分别测试装 Belmont Minimap、只装 Belmont UI、什么都不装三种情况（发布前）。
- [ ] 中文和英文游戏语言下，设置页文字都能正常显示，没有方框或缺行。
- [ ] 整合包（发布前）：在没有装过 BepInEx 的游戏目录（可以先把现有的 `BepInEx/`、`dotnet/`、`winhttp.dll`、`doorstop_config.ini` 移到别处）解压 `-with-BepInEx.zip`，首次启动能完成生成并加载本 mod。测完把原来的文件移回来。

## 高速反应

- [ ] 移动、起步、急停、转身明显更快；减速区域、水中等原版减速仍然有效。
- [ ] 地面连招和空中攻击的命中帧和动画对得上，伤害正常。
- [ ] 剑盾 / 鞭 / 大剑：前摇约 1.25x～1.4x 时，点按（不按住）仍能出地面攻击；连点鞭子不卡在起手。
- [ ] 大剑蓄力第二下、剑盾钩锁下砸 / 对僵尸：能打中，不会只推开无伤。
- [ ] 钩锁出手、收回更快，摆荡速度不变。
- [ ] 镜子前按下立即进入；关闭"镜子即按即进"后恢复按住。
- [ ] 镜头跟随：快速移动、被弹射时镜头跟得上；房间切换、过场镜头正常。
- [ ] 右摇杆观察范围变大，松开后回正，不会抖动或越过中心。

## 闪避与受身

- [ ] 滑铲、后撤步的位移阶段穿过敌人攻击不掉血，有闪光；收招阶段会被打。
- [ ] 闪避时碰到陷阱、即死区域仍然受伤或死亡。
- [ ] 被击飞后按跳立即恢复控制，有特效，不会被惯性带飞。
- [ ] 过场或剧情锁定输入时按跳不会受身。

## 弹反

- [ ] 未解锁弹反时，攻击不会弹反。
- [ ] 解锁后，普通攻击在敌人攻击命中瞬间能弹反，有特效和音效，攻击动作不被打断。
- [ ] 弹反成功后，敌人同一套连段的后续命中不会造成伤害。
- [ ] 原版弹反动作仍然正常。

## 钩锁辅助

- [ ] 默认设置下，附近没有可钩物时按钩锁仍会出钩（和原版一样）；打开"无目标时不出钩锁"后，按钩锁不出钩、不打断当前动作。
- [ ] 只有一个高亮锚点时，背对它也能钩中。
- [ ] 被墙挡住或超出范围的锚点不高亮；走到能钩到的位置时亮起。
- [ ] 关闭"只高亮钩得到的目标"后，高亮立即恢复原版。
- [ ] 空中、爬墙后下落时，附近有钩得到的钩点，按钩锁能出钩。

## 塔罗牌

- [ ] 上+Y、下+Y、LT+Y、R3、RB+Y、RB+下+Y、RB+R3 分别释放对应的牌，动画和扣的 MP 是那张牌自己的；当前装备的牌不变。
- [ ] MODS 列表有三个：奥创模式、奥创模式 - 快速操作、奥创模式 - 法术优化。
- [ ] 快速操作：左右键换装、上下键换法术、快速施法三个开关；下面 16 张牌选组合键。
- [ ] 左右只切最高级各类型武器；上下只切未设快速施法的法术；十字键不走路；摇杆+Y 快速施法仍可用。
- [ ] 挥砍中按左右换装：武器要等这次攻击结束或进入可连段间隙才换上，动画不被打断；连按仍按次序轮换。
- [ ] 法术优化：时空飞冲无敌、圣十字架撞墙不消失。
- [ ] 快速施法的牌和当前装备的牌不会叠在一起放（准备动作和释放动作是同一张牌）。
- [ ] 没获得的牌，组合键按原版处理；赦免获得前 R3 放诅咒之火，获得后放赦免。
- [ ] LT+Y 时护盾和弹反同时出现，不会再放第二次护盾。
- [ ] 用 R3 放赦免、RB+R3 放灵魂收割时，按住能蓄满，蓄力中松开和原版松开 Y 一样。
- [ ] 装备塔罗牌页面，有快捷键的牌描述末尾显示"按下/按住 组合键 快速施法"，图标正确（LT、RB、R3 是对应键的图标，不是菜单键）；没有快捷键的牌不显示；关闭"快速施法"后不显示。
- [ ] 时空飞冲从起跳到落地被敌人打中不掉血；碰到陷阱仍然受伤。

## 成长

- [ ] 获得经验升级时 HP、MP 回满；读档不会触发。
- [ ] 击碎经验雕像，经验不够升级时会补足升一级；经验本来就够时只升原本的级数。

## 镜子

- [ ] 隐士任务之后，用过的存档室镜子能传送；快速传送菜单可用。
- [ ] 没用过的存档室镜子仍然只能存档，不能传送。
- [ ] 站在可传送的镜子前，提示是"保存"（存档点）或"信息"（其他镜子）加"下 传送"，按键图标正确；切换手柄和键盘后图标跟着变；离开后提示恢复原样。

## 魔导器

- [ ] 获得正面魔导器后立即生效，不占槽位。
- [ ] 魔导器菜单里仍然可以把任何魔导器装进槽位、卸下（回归 bug：曾经所有魔导器都显示为已装备而装不进去）。
- [ ] 默认设置下，五个负面魔导器不会自动生效：焦黑之心生效时不能喝血瓶，地狱徽记生效时 MP 回不满，可以用来确认。
- [ ] 打开"自动装备负面魔导器"后它们生效，关闭后约一秒内撤掉（已装进槽位的不受影响）。
- [ ] 没获得洞幽石时，靠近可破坏的隐藏墙壁也会显示；关闭选项后不显示。
- [ ] 存档、读档后魔导器状态正常；卸载 mod 后存档与原版一致。
